# Birthday Celebration Web App ✨🎂

An interactive, responsive, and aesthetic birthday celebration web application built with React, Vite, Framer Motion, and Tailwind CSS.

## 🚀 Features
- 🎈 **Interactive Mini-Games**: Balloon Popper, 3D Cake Baker, Friendship Trivia Quiz, Fortune Cookie, Mystery Gift Box, and Chime Synthesizer Piano.
- 🎨 **Celebration Studio**: Fireworks Lightshow Sandbox, Starry Wish Constellation, Polaroid Wall, Custom Greeting Card Generator, and Friendship Bingo.
- 🌈 **Theme Engine**: 6 distinct aesthetic celebration themes (Sunset Glow, Midnight Starlight, Neon Party, Emerald Fest, Rose Gold, Pastel Dream).
- 🏆 **Trophy & Achievement System**: 14 unlockable celebration milestones with toast banners and point tracking.
- 🎵 **Web Audio Synth**: Pure Web Audio oscillator synthesis for pops, sparkles, birthday melodies, and fanfare without external audio assets.
- 📱 **Mobile First**: Glassmorphism UI, floating action dock, touch-friendly interactions.

## 🛠️ Tech Stack
- **React 19**
- **Vite 8**
- **Tailwind CSS 4**
- **Framer Motion**
- **Lucide Icons**
- **Canvas Confetti**
